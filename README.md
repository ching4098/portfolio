# Portfolio

The personal site of ZX Ching, a backend engineer at Rakuten in Tokyo who runs on coffee.

**Live at https://ching4098.github.io/portfolio/**

It covers where I've worked, what I build, a few side projects (one of them a live maze-solver race you can watch in the browser), the VRSight demo from CHI 2025, and my resume.

Built with React, Vite, Tailwind CSS and Framer Motion. Every push to `main` deploys to GitHub Pages.

## Run it locally

```bash
npm ci
npm run dev
```
